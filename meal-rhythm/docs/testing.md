## 每次修改必须执行

```sh
npm run verify
```

修改接口时额外执行 `npm run contracts` 并审阅生成文件。修改 iOS 时应在 Mac 上运行 Xcode 测试；Windows 的后端测试通过不能替代 iOS 编译。

## 基础设施测试

`tests/infrastructure.test.ts` 和 `tests/postgres-api.test.ts` 仅在明确配置独立测试服务时运行。Windows 已通过 `npm run test:postgres` 实际启动 PostgreSQL 17、执行迁移并运行 5 项测试，覆盖并发事务、重连、幂等记餐、版本冲突、事务回滚、账号隔离以及删除竞态。Redis 测试尚未执行，Docker 构建仍待容器环境。

临时实例只监听 127.0.0.1，使用随机端口和密码，不接入真实用户数据库。测试结束先停止实例，再校验规范化路径并移除本次独立目录。清理保护有正反例测试。运行器另有 `--self-test-failure` 开关，已验证故意失败时清理仍执行且进程返回 1，避免依赖库退出钩子掩盖测试失败。

PostgreSQL 二进制通过 [embedded-postgres 项目](https://github.com/leinelissen/embedded-postgres) 的锁定版本获取；只用于项目级测试，不创建系统服务或账户。
